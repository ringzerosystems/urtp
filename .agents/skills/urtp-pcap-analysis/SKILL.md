# urtp PCAP Capture & Wireshark Media Analysis

Inspect, convert, and play back RTP packet captures recorded by `urtp` via Docker volume mounts (`./pcap`).

## PCAP Recording in Docker

When `urtp` is started with PCAP recording enabled (e.g. via `docker compose --env-file .env.pcap up -d` or `docker compose --env-file .env.full up -d`), the container binds `./pcap` on the host to `/pcap` inside the container.
- All ingress and transcoded egress RTP/RTCP packets are captured with nanosecond-resolution timestamps.
- Captures are saved to `./pcap/session_<port>.pcap`.

## Wireshark Playback & Stream Analysis

### 1. Opening the Capture
```bash
wireshark ./pcap/session_30002.pcap &
```

### 2. Live Audio Playback in Wireshark
1. In the top menu, navigate to:
   **Telephony** $\to$ **RTP** $\to$ **RTP Player**
2. Select the audio stream (e.g., Payload Type `0` for PCMU or `96` for Opus).
3. Click **Play Audio** to listen to the exact audio decoded from the captured packets.

### 3. Jitter & Loss Stream Analysis in Wireshark
1. In the top menu, navigate to:
   **Telephony** $\to$ **RTP** $\to$ **RTP Streams**
2. Select the stream and click **Stream Analysis**.
3. Inspect:
   - **Max Jitter & Mean Jitter**: Verifies transit arrival variance.
   - **Packets Lost & Out of Sequence**: Verifies simulated drop and reorder impairments.
   - **Graph Delta / Graph Jitter**: Visual plot of arrival time differences.

## Command-Line Conversion & Automated Inspection

### 1. Convert PCAP to Playable WAV via FFmpeg
Extract the raw RTP audio stream directly into an uncompressed WAV file:
```bash
ffmpeg -y -i ./pcap/session_30002.pcap ./pcap/session_30002.wav
```

Listen to the extracted WAV:
```bash
ffplay -nodisp -autoexit ./pcap/session_30002.wav
```

### 2. Inspect RTP Streams with Tshark
Print stream summaries (SSRC, payload type, packet count, packet loss, average jitter):
```bash
tshark -r ./pcap/session_30002.pcap -q -z rtp,streams
```

Print detailed per-packet sequence numbers and timestamps:
```bash
tshark -r ./pcap/session_30002.pcap -Y "rtp" -T fields \
    -e frame.time_relative \
    -e ip.src \
    -e udp.srcport \
    -e rtp.seq \
    -e rtp.timestamp \
    -e rtp.p_type
```
